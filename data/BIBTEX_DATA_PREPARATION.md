# RefGuard 数据集分布设计

本数据集面向引用真实性检测任务，单条样本对应一条参考文献记录，标签分为真实文献 `real` 与虚假文献 `hallucination`。设计目标约 3000 条，覆盖跨学科（中图法 CLC 大类）、中英双语与多类型文献。

数据由 `scripts/` 下采集/构造脚本生成源文件 `data/citation_dataset_final_v4.json`，再经 `scripts/build_refguard_input.py` 生成评测输入 `data/refguard_input.jsonl`。

## 学术诚信约束

- 合成幻觉只作为 benchmark 负样本存在，**绝不**进入任何论文正文的参考文献表。
- 真实文献标签由**独立证据**确立（DOI 经 doi.org 解析、或源 API 权威条目），**不**由 RefGuard 自身判定，避免循环标注。
- 只采公开可文档化元数据：**不抓 Google Scholar、不用 CNKI / 登录 / 私有数据**，不存全文、凭据、cookie。
- 每条幻觉记录在 `note` 写明构造方法；正式再分发前逐条核查来源许可。

## 1. 总体规模

下表为**设计目标**；实际产出 v4 = 2537 条（真实 1937 / 幻觉 600），实际分布与差距说明见 `DATASET_CARD.md`。差距集中在中文真实文献——OpenAlex `has_doi:true` 中文供给采尽所致，未为凑数引入不可独立核验的记录。

| 类别 | 数量（目标）| 占比 |
| --- | ---: | ---: |
| 真实文献 | 2400 | 80% |
| 虚假文献 | 600 | 20% |
| 合计 | 3000 | 100% |

## 2. 标签 × 语种（EN 70% / ZH 30%）

| 语种 | 真实 | 虚假 | 合计 |
| --- | ---: | ---: | ---: |
| 英文 | 1680 | 420 | 2100 |
| 中文 | 720 | 180 | 900 |
| 合计 | 2400 | 600 | 3000 |

中文文献只取有 DOI、期刊官网或出版社页等公开可验证记录；来源走 OpenAlex(`language=zh`) / Crossref 中文期刊 / DOAJ / PubMed 中文医学，**不纳入仅 CNKI 可验证的记录**。

## 5. 虚假文献来源与类型（600）

| 来源 | 数量 | 类型构成 |
| --- | ---: | --- |
| `citation_hallucination.json`（NeurIPS 2025 GPTZero 真实幻觉） | 100 | 标题篡改 25 / DOI捏造 22 / 作者伪造 10 / 完全虚构 43（全 EN/会议） |
| 合成扰动（由真实引用改造） | 500 | 标题篡改 / 作者伪造 / DOI捏造 / venue年份错配 / 完全虚构 |

合成 500 条按语种切分 EN 320 / ZH 180；保留来源真实记录的 CLC/语种/类型，并把 `source_paper` 指向原记录以支撑无泄漏划分。前 4 类由真实记录扰动（已知为假）；「DOI捏造」生成不解析的 DOI，「完全虚构」在 OpenAlex 负向核验题名无命中。

## 6. 数据划分

| 子集 | 数量 | 占比 | 用途 |
| --- | ---: | ---: | --- |
| development | 600 | 20% | 阈值设计与规则调试 |
| test | 2400 | 80% | 最终实验评估 |
| 合计 | 3000 | 100% | - |

按来源论文（`source_paper`，无来源则记录自成一组）分组划分，避免同源参考文献跨 development 与 test 泄漏。
